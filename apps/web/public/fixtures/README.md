# Bundled fixtures

Demonstration assets, not user uploads. Phase 1 photo notes reference these;
real uploads land in Phase 3 with the S3 media pipeline.

- `lake.jpg`: sample landscape downloaded from [Unsplash](https://images.unsplash.com/photo-1501785888041-af3ef285b470?w=1000&q=85&fit=crop), used under the [Unsplash License](https://unsplash.com/license).
- `living-room.png`, `moonlit-bedroom.png`: carried over from v1 (`archive/noted-v1`); generated art owned by this project, renamed on extract.
- `reels/`: sample clips for the Phase 3 TV feed (see `reels/README.md`).
