# Public prototype fixtures

These are bundled demonstration assets, not user uploads. Future member media must use the private storage boundary in PLAN.md.

- `lake.jpg`: sample landscape downloaded from [Unsplash image source](https://images.unsplash.com/photo-1501785888041-af3ef285b470?w=1000&q=85&fit=crop), used under the [Unsplash License](https://unsplash.com/license). Local copy keeps the prototype independent of runtime image services.
- `dinner.wav`: locally synthesized demonstration speech: “Hey everyone, dinner is at six thirty. See you at home!” It is not a user's recording.
- DM Sans and Caveat are installed through Fontsource and bundled locally. Their licenses ship in the corresponding packages.
